# 宣传片 · 制作说明

成片：`promo/out/社畜人设卡_宣传片_1080x1920.mp4`（33.6 秒 · 1080×1920 · 30fps · H.264 + AAC）

## 为什么这样做

片子里的每一个数字都能在仓库里找到出处，没有一句是编的：

| 片中文案 | 出处 |
|---|---|
| 47 个商品 | `tests/fixtures/lunch_menu_raw.json` 午餐时段 47 项 |
| 菜单 ¥15.90 → 结账 ¥26.50 | 真实 `query-meals` 与 `calculate-price` 返回值（随单购早餐卡差额） |
| 收藏门店 5 家，跨 2 个城市 | `query-nearby-stores` 返回（汕头 4 + 厦门 1） |
| 加班狗 → 龙焰鸡腿堡三件套 ¥26.90 | 真实午餐菜单 + `scripts/persona_engine.py` 打分 + 真实核价 |
| 12 个人设 | `data/personas.json` |

卡片画面是把 `scripts/card.py` 真实渲染的 `card.html` 用 Playwright 以 2x 截成 PNG
（`promo/assets/card_hero.png`），不是另画的设计稿——所以你看到的就是用户会看到的。

## 时间轴

| 时间 | 段落 | 内容 |
|---|---|---|
| 0.0–3.4s | 01 提问 | 23:47 工位，「今天吃什么？」 |
| 3.4–7.5s | 01 提问 | 三连痛点：选择过载 / 价格不透明 / 券不知道怎么叠 |
| 7.5–11.6s | 02 一句话 | 开灯式转场，品牌登场；输入「今天加班，来点狠的」→ 匹配「加班狗」 |
| 11.6–19.5s | 03 出卡 | 真实人设卡进场，三步高亮：① 立人设 ② 挑真实餐品 ③ 核价 |
| 20.0–24.8s | 04 两种用法 | Roll / 点餐双模式 + 12 人设墙 |
| 24.9–29.2s | 05 真实数据 | 门店 / 菜单 / 核价三项实证 →「菜单是活的，人设是算的」 |
| 29.2–33.6s | 收尾 | 品牌收束 + 运行命令，最后 0.7 秒淡出 |

底部一直有一条章节页脚（`01 / 05` …），压在安全区上方，不挡内容。

## 技术实现

不是用模板拼的，整片是一个「时间轴函数」：

- `video.html` 里只有一个 `tick(t)`，所有元素的位置、透明度、缩放都由绝对时间 `t` 算出来，
  没有 CSS 过渡、没有动画库里存状态 → 同一帧永远渲染同一个画面，可以逐帧截图。
- `capture.py` 用 Playwright 打开页面，关掉自动播放（`?still=1`），
  对每一帧调用 `window.renderAt(ms)` 再截图，得到 `promo/frames/f00000.jpg … f01007.jpg`（1008 帧）。
  渲染目录不入库（约 60MB），需要时重跑即可。
- `audio.py` 用 numpy 合成配乐与音效：和声垫 + 低音 + 轻鼓 + 空气层，
  再按镜头节点插入 whoosh / blip / 确认音，最后过一遍总线慢压缩。
- `encode.sh` 用 ffmpeg 合成 H.264 + AAC。

所以改一个字幕时间只要改一个数字，重跑 `capture.py` 即可，不会出现"改完动效对不上"的问题。

## 重新生成

```bash
# 1) 素材（真实菜单 + 真实核价 → 卡片 PNG）
python3 promo/make_assets.py

# 2) 关键帧检查（改版式时先看这个）
python3 promo/capture.py --stills 2700,11100,15600 --out promo/qa

# 3) 配乐
python3 promo/audio.py

# 4) 全片逐帧 + 合成
python3 promo/capture.py --all --fps 30
bash promo/encode.sh
```

预览（带声音、可实时播放）：直接用浏览器打开 `promo/video.html`。

## 设计说明

- **竖版 1080×1920**：这类内容主要在视频号 / 小红书 / 抖音分发。
- **暗场 → 开灯**：前 7.5 秒用深棕近黑讲"社畜的深夜"，再用一个从中心扩散的圆形把画面
  "点亮"成奶油色，完成从问题到产品的情绪切换。
- **字体**：正文用系统中文字体，引语用宋体（`Songti SC`），数字与标签用等宽体，
  让"产品名"和"技术细节"在视觉上分层。
- **配色**：奶油底 `#FBF6EC` + 金 `#C79A5B` + 深棕 `#241C14`，
  与卡片本身一套色，保证片子和交付物是同一个东西。
- **不出现真人、不出现 LOGO 变形**：卡片本身的红黄顶条就是品牌信号，不需要额外贴标。
