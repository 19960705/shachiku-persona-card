# 《18:59》快剪玩梗版 · 制作说明

成片：`promo/fun/out/社畜人设卡_18点59_1080x1920.mp4`
（23.4 秒 · 1080×1920 · 30fps · H.264 + AAC · 16:9 竖版）

这是社畜人设卡的第二支宣传片。第一支（`promo/`，33.6 秒）走的是文艺克制路线，
这一支换了完全相反的做法：**红黄撞色、粗黑描边、快剪、玩梗**，目标是在前 3 秒就让人
觉得「这说的就是我」。

## 叙事结构

整片是一条**先共情、后反转**的曲线。前 9 秒不讲产品，只讲你下班时的样子。

| 时间 | 段落 | 内容 | 笑点来源 |
|---|---|---|---|
| 0–1.9s | 18:59 | 时钟跳成 19:00，红字发亮 →「下班了。」「但没人动。」 | 每个人都经历过的「下班了但没人走」 |
| 1.9–3.8s | 老板 | 老板：「这个需求今天能上吗」→ 你：「能……」 | 打工人第一反射：先答应再想办法 |
| 3.8–6.3s | 滑动地狱 | 真实菜单 47 项飞速滚过，计时器 8:12→8:47，红框框住第 47 个，贴纸「上个月点过 6 次」；底栏从「47 / 47」变成按钮「算了」 | 翻了 8 分钟，一个都没选 |
| 6.3–8.9s | 价格背刺 | 菜单 ¥15.90 被红笔划掉，¥26.50 砸下；「随单购早餐卡 ¥10.60」被打上勾；「你没勾，但已经勾上了」 | **全片最强笑点：默认勾选** |
| 8.9–10.1s | 放弃 | 「老三样」三个字逐个砸下来；「因为决定，比饿更累」；「这是你第 4,382 次做同一个决定」 | 「老三样」是共用的痛 |
| 10.1–11.3s | 抽卡 | 老虎机转轴 48 格带运动模糊急停 →「叮。」 | 把选择权交出去的那一刻 |
| 11.3–15.6s | 出卡 | 真实卡片从天砸下 + 冲击波，三枚印章依次盖下：人设锁定 / 真实在售 / ¥26.90 已核验 →「3 秒。不用你选。」 | 爽感，不是笑点 |
| 15.6–18.0s | 三连 | 「12 种人设」（12 格 chip 逐个弹出）/「说人话就行」（4 条真实用户句式）/「或者 Roll」（骰子转 340°） | 直给功能 |

让观众喘一口气看卡片细节。

## 画面设计

**配色**：麦当劳红 `#DA2A1C` / 黄 `#FFC72C` / 墨黑 `#141110` / 奶油 `#FBF6EC`。
不做渐变和阴影柔化，一律用 4–6px 硬边框 + 硬投影（`box-shadow: 12px 12px 0 #141110`），
贴纸感、海报感，缩到手机小窗也认得出。

**字体处理**：PingFang 在部分系统上 `font-weight:900` 会被合成加粗、渲染不一致，
所以标题统一加 `-webkit-text-stroke: 1.5px currentColor` 补厚，保证逐帧截图稳定。

**每个镜头都有实拍质感**：颗粒（SVG feTurbulence）、扫描线、暗角三层叠加。
暗场颗粒更重（0.10），亮场更轻（0.062），这是为了压住 H.264 在近黑渐变上的色块。

## 技术做法

### 一条时间轴函数

整个片子仍然是**一个纯函数 `tick(t)`**，没有任何 CSS 过渡、动画库或 `setTimeout`：

```js
window.renderAt = ms => tick(ms);
```

任意时刻 t 调一次 `renderAt(t)`，就能确定性地重建那一帧的所有状态——
透明度、位移、缩放、旋转、文字内容、颗粒偏移。

`capture.py` 用 Playwright 打开带 `?still=1` 的页面（关掉自动播放），
逐帧调 `renderAt(ms)` 再截图，得到 702 张 JPEG，最后交给 ffmpeg 合成。

好处是：改一个时间点只要改一个数字，重跑一次，不会有「上次好像比这次快」的问题。

### 素材是真的

- **卡片**：`promo/fun/assets/card_hero.png` 是 `card.py` 渲染真实数据后，
  用 Playwright 以 2 倍缩放截下来的图。片子里看到的就是用户会拿到的那张卡。
- **47 项菜单**：滚动列表里的名字和价格全部来自 `tests/fixtures/lunch_menu_raw.json`
  （2026-10-21 10:59 午餐时段的真实 MCP 响应），没有一项是编的。
- **¥15.90 → ¥26.50**：这是 `calculate-price` 实测差额，差在「随单购早餐卡」。
- **5 家 · 2 城**：`query-nearby-stores` 返回的收藏门店分布。

### 音频

`promo/fun/audio.py` 用 numpy 从零合成，不依赖任何采样：

- **底鼓**：46Hz + 150Hz 指数扫频，带 3ms 噪声 click
- **拍手**：带通噪声三次 8ms 重触发，模拟多人拍手
- **贝斯**：4 次谐波叠加的锯齿感正弦，8 分音符跑 Am7–Fmaj7–C–G
- **拨弦**：5 次谐波 + 17/s 指数衰减，11.3 秒后进 16 分音符琶音
- **音效**：时钟滴答、微信弹出（两音上行）、发消息、滑动（噪声扫频）、
  马克笔划纸（带颤音的正弦+噪声）、落卡（反转扫频+42Hz boom）、
  盖章（噪声+低频双层）、老虎机棘轮（间隔从 62ms 加速到 18ms）、
  铃（非谐波 2.76/5.40 倍频）、硬币三连音

**母带链**：倾斜 EQ（砍 55Hz 以下、抬 1.5kHz 以上）→ 归一化 → 分块慢压缩
→ 两级软限幅（tanh 1.9 / 1.7）。最终 -16.1 dBFS RMS，峰值 -0.4 dBFS。

这里踩过一个坑：第一版 bass 和 kick 把 20–150Hz 堆到比中频高 13dB，
在监听耳机上很爽，但手机外放几乎听不见低频，整体就变成「又闷又小」。
把 sub 从 0.95 降到 0.40、抬高中高频之后才正常。

## 怎么改

```bash
# 只看某个时间点（毫秒）
python3 promo/fun/capture.py --stills 12000,15000

# 重渲整片（约 702 帧）
rm -rf promo/fun/frames && python3 promo/fun/capture.py --all --fps 30

# 重新合成
bash promo/fun/encode.sh
```

改文案或时间点：直接编辑 `promo/fun/video.html` 里 `tick()` 对应的
`seg(t, 起, 止)` 数字，以及 `T` 对象里的段落边界。
改配乐：编辑 `promo/fun/audio.py` 的 `CHORDS` / `ROOTS` / 音效时间表，重跑即可。

渲染出来的 `frames/`（约 45MB）不入库，随时可以重跑。
